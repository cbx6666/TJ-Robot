# robot_tasks

## 1. 包定位

`robot_tasks` 是任务层功能包，负责承接任务文本、任务状态和任务编排逻辑。  
当前实现规模较小，但其职责边界已经明确：它位于交互层和执行层之间，负责把输入任务转化为系统内部可处理的任务流。

## 2. 当前职责

- 接收任务输入
- 维护任务状态
- 对接交互层和执行层

## 3. 当前节点

- `task_manager_node`
  - 负责任务文本接入、状态发布以及基础调度占位逻辑

## 4. 后续扩展方向

后续可在本包内继续扩展：

- 任务状态机
- 调度逻辑
- LLM / 规则混合任务适配层
- 房间搜索、行为树、Agent 调度等更高层任务逻辑

## 5. 维护建议

- 任务编排逻辑应集中在本包，不要分散到交互包或 bringup 包
- 如需增加复杂任务流，优先扩展任务层而不是直接在脚本中拼接行为
